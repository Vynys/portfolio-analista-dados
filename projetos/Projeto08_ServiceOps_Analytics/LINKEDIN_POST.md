🚀 **Novo projeto de portfólio: ServiceOps Analytics Dashboard**

Nos últimos dias desenvolvi um dashboard operacional interativo do zero, com foco em transformar dados de operações de TI em uma experiência de análise mais rápida, visual e explorável.

O projeto foi construído com **HTML, CSS, JavaScript, Vite e Chart.js**, sem depender de uma ferramenta de BI tradicional para a camada de visualização.

Algumas funcionalidades que implementei:

- KPIs de volume, horas, TMA, TMR e SLA;
- análise diária e histórica de chamados;
- filtros cruzados entre gráficos e cards;
- comparação entre plataformas operacionais;
- acompanhamento de backlog e aging;
- identificação de chamados com SLA rompido;
- drill-down dos KPIs para tabelas detalhadas;
- filtros individuais por coluna;
- visual responsivo para diferentes resoluções;
- otimizações de performance para grandes volumes de elementos gráficos;
- geração automática de dados sintéticos para demonstração.

Um dos pontos que mais gostei de trabalhar foi a interação entre os gráficos: ao selecionar um período, prioridade, status ou plataforma, os demais elementos da mesma análise respondem ao filtro de forma integrada.

🔒 **Todo o conteúdo publicado utiliza dados 100% fictícios e foi preparado exclusivamente como projeto pessoal de portfólio.**

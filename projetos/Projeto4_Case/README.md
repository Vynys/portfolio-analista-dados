# Projeto 04 – Dashboard com Python e Power BI

## 🎯 Objetivo
Este projeto demonstra a integração entre Python e Power BI para automatizar análises financeiras.

## 📁 Estrutura
- **dados/** → bases e fontes de dados
- **imagens/** → screenshots do dashboard
- **medidas/** → cálculos e fórmulas DAX/Python
- **modelo/** → arquivo .pbix do Power BI
- **relatorio/** → documentação e relatório Word

## 🧰 Tecnologias
- Python 3.x
- Pandas
- Power BI
- YFinance API

## 📊 Resultados
Dashboard automatizado e integrado com dados financeiros em tempo real.

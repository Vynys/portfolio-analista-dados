1️⃣ OBJETIVO DO PROJETO

O desafio da JAAR Consult teve como objetivo principal construir um dashboard interativo de indicadores operacionais e financeiros, demonstrando a capacidade de integração entre Python e Power BI para análise de dados reais de uma empresa de consultoria.

O foco era:

Consolidar diferentes bases de dados (vendas, clientes, produtividade e metas);

Automatizar a limpeza e preparação dos dados;

Criar medidas DAX estratégicas para indicadores de desempenho;

Apresentar insights visuais claros e acionáveis.

3️⃣ FONTES DE DADOS UTILIZADAS

As bases disponibilizadas continham informações sobre:

Base	Descrição	Campos principais

4️⃣ TRATAMENTO E LIMPEZA DE DADOS (PYTHON)

O processo de ETL foi desenvolvido com Python (Pandas), utilizando Jupyter Notebook.

Principais etapas:

Importação das bibliotecas

import pandas as pd
import numpy as np


Leitura dos arquivos

vendas = pd.read_excel('Base_Vendas.xlsx')
clientes = pd.read_csv('Clientes.csv')
equipe = pd.read_excel('Equipe.xlsx')


Padronização de colunas

Nomes de colunas foram convertidos para minúsculas e sem espaços.

Exemplo:

vendas.columns = vendas.columns.str.lower().str.replace(" ", "_")


Tratamento de nulos

Substituição de campos vazios por “Não informado”.

Conversão de tipos (datas e valores).

Remoção de duplicatas

vendas.drop_duplicates(inplace=True)


Junção das tabelas

base_final = vendas.merge(clientes, on='id_cliente', how='left') \
                   .merge(equipe, on='id_vendedor', how='left')


Exportação da base tratada

base_final.to_csv('Base_Final_JAAR.csv', index=False)


Essa base foi utilizada como fonte principal do Power BI.

5️⃣ MODELAGEM DE DADOS (POWER BI)

O modelo foi construído no formato Star Schema (Esquema Estrela), com:

Tabelas fato:

Fato_Vendas

Fato_Financeiro

Tabelas dimensão:

Dim_Clientes

Dim_Equipe

Dim_Tempo

Dim_Produto

Relacionamentos:

1:N entre Dim_Tempo[Data] e Fato_Vendas[Data]

1:N entre Dim_Clientes[ID_Cliente] e Fato_Vendas[ID_Cliente]

1:N entre Dim_Equipe[ID_Vendedor] e Fato_Vendas[ID_Vendedor]

6️⃣ MEDIDAS DAX DESENVOLVIDAS

As principais medidas criadas no Power BI foram:

Total de Vendas

Total Vendas = SUM(Fato_Vendas[Valor Total])


Ticket Médio

Ticket Médio = DIVIDE([Total Vendas], COUNTROWS(Fato_Vendas))


Lucro Bruto (%)

Margem Bruta (%) = DIVIDE(SUM(Fato_Vendas[Lucro Bruto]), [Total Vendas])


Vendas YTD

Vendas YTD = TOTALYTD([Total Vendas], Dim_Tempo[Data])


Crescimento Anual (%)

Crescimento Anual (%) =
VAR VendasLY = CALCULATE([Total Vendas], SAMEPERIODLASTYEAR(Dim_Tempo[Data]))
RETURN DIVIDE([Total Vendas] - VendasLY, VendasLY)


Ranking de Vendedores

Ranking Vendas = RANKX(ALL(Dim_Equipe[Vendedor]), [Total Vendas], , DESC)
